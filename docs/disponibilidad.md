# Disponibilidad técnica y de despliegue

## Respuesta inicial

El equipo dispone de computadores personales, conexión a Internet y acceso a herramientas de desarrollo y control de versiones como Git y GitHub. El trabajo podrá realizarse de forma local y colaborativa mediante el repositorio del proyecto.

Para las primeras demostraciones se contempla un despliegue de prueba en un servicio gratuito, académico o proporcionado por la universidad. Todavía deben confirmarse las restricciones institucionales, las tecnologías autorizadas, la disponibilidad de credenciales y los servicios externos que podrían emplearse, especialmente para autenticación, almacenamiento y pagos.

## Datos por confirmar

- Sistema operativo y herramientas disponibles para cada integrante.
- Posibilidad de ejecutar contenedores con Docker.
- Servicio o infraestructura disponible para el despliegue.
- Acceso a una base de datos administrada.
- Disponibilidad de credenciales de prueba para servicios de pago.
- Restricciones institucionales sobre datos personales y publicación en Internet.
